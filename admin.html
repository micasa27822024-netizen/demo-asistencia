Agregar Empleado con Acceso

Registrá un nuevo empleado y su credencial de acceso. El horario y los objetivos se configuran luego desde Configurar.

Migrar empleados anteriores

Crea el acceso de los empleados que se cargaron antes y normaliza sus fichas. Las fichadas históricas no se pierden porque se vinculan por el número de legajo. Ejecutalo una sola vez; los que ya tienen acceso se omiten automáticamente.

Sincronizar identidades (/usuarios)

Crea el mapa /usuarios/<uid> = { legajo, rol } que las Reglas de Seguridad necesitan para que cada empleado pueda ver solo sus propios datos. Recorre las fichas de /personal y completa las que falten. No modifica a quienes ya sean admin o supervisor. Es idempotente: podés ejecutarlo las veces que quieras.

Proteger PIN (hash + salt)

Reemplaza el PIN en texto plano por un hash con salt en cada ficha, para que nadie pueda leer los PIN aunque acceda a la base. El ingreso por PIN sigue funcionando igual. Ejecutalo una sola vez; las fichas ya protegidas se omiten.

Limpiar PIN en fichadas

Elimina el PIN en texto plano que quedó guardado dentro de las fichadas históricas (/fichadas y /fichadasPendientes). No borra ninguna fichada ni afecta el acceso; solo quita ese dato sensible. Las fichadas nuevas ya no lo guardan.

Fichaje sin conexión (offline)

Permite que los dispositivos registrados guarden fichadas cuando no hay señal y las sincronicen firmadas al recuperar internet. Está desactivado por defecto. Solo los dispositivos dados de alta abajo pueden fichar offline.

Antigüedad máxima aceptada de un lote offline al sincronizar. Por defecto 168 h (7 días). Los lotes más viejos se rechazan.

Dar de alta un dispositivo

El servidor genera un identificador y un secreto único. Copiá el código de vinculación en el dispositivo físico (pantalla de fichaje > Vincular dispositivo). El secreto se muestra una sola vez.

Separá los legajos con coma. Si lo dejás vacío, cualquier legajo válido puede fichar desde este dispositivo.

Reglas de tolerancia y radio de fichaje

Estos valores definen cómo se clasifican las fichadas (tolerancia, llegada tarde, salida anticipada y horas extra) y a qué distancia del objetivo puede fichar un empleado. Aplican como valor por defecto para todos los objetivos.

Desde el inicio del turno hasta este minuto = tolerancia (amarillo). A partir del minuto siguiente = llegada tarde (rojo).

Tras el fin del turno hay este margen para marcar salida. Si se supera, se computan como horas extra TODOS los minutos desde el fin del turno (no solo el excedente).

Distancia máxima al objetivo para poder fichar. Por defecto 100 m.

Umbral de precisión GPS que valida el servidor (Worker). Si la señal reportada por el dispositivo es peor que este valor, la fichada se BLOQUEA. 0 = desactivado (no bloquea por precisión).

Modo de dispositivo de fichaje

Define cómo se comporta la sesión en la pantalla de fichaje de los empleados. Se aplica a todos los dispositivos.
